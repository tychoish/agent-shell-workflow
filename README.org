* Overview

~agent-shell-prompt~ provides dynamic prompt composition, template expansion,
and dispatching for ~agent-shell~ sessions. It enables structured prompt
authoring, file-based prompt templates, pre/post evaluation hooks, and ACR/Transient
interactive prompt selection menus.

* Features

- *Prompt Templates*: Configurable variable substitutions with regex extraction.
- *Prompt Library*: Discoverable library of reusable prompt definitions (~agent-shell-prompt-library~).
- *Interactive Menus*: Fast transient and completing-read selection menus (~agent-shell-prompt-menu~).
- *Pluggable Dispatch*: Extensible target buffer resolution via ~agent-shell-prompt-dispatch-target-functions~ hook.
- *Zero Queue Coupling*: Works independently or alongside ~agent-shell-queue~.

* Installation

** ELPAish
#+BEGIN_SRC elisp
(use-package agent-shell-prompt
  :ensure t)
#+END_SRC

* Usage

#+BEGIN_SRC elisp
